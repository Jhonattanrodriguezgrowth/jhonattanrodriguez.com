# Checklist de rutas (verificación visual)

Tras cambios de UI, layout o metadatos, revisar manualmente:

| Ruta            | Qué comprobar                                      |
|-----------------|-----------------------------------------------------|
| `/`             | Home, hero, tarjetas de servicios, CTA, tema claro/oscuro |
| `/growth`       | Hero, acordeones MetaAds, mentoría, consultoría, CTAs |
| `/filmmaker`    | Hero, problema, audiencia, planes expandibles, proceso |
| `/ia-builder`   | Hero estilo terminal, stack, proyectos, filtros, CTA |
| `/mi-historia`  | Hero, línea de tiempo expandible, CTA final       |

Incluye navegación desde el navbar y enlaces internos (por ejemplo “Volver al inicio” en mi historia).
